# Emotion Analyzer

## Project Overview
Emotion Analyzer is a web application built using Django that analyzes user-entered text and detects emotions such as Happy, Sad, Angry, and Neutral.

## Technologies Used
- Python
- Django
- HTML
- CSS

## Features
- User-friendly interface
- Text emotion detection
- Instant results
- Responsive design

## Project Structure
emotion_analyzer/
├── analyzer/
├── emotion_analyzer/
├── templates/
├── manage.py
└── README.md

## How to Run the Project

1. Install Django

pip install django

2. Run migrations

python manage.py migrate

3. Start the server

python manage.py runserver

4. Open in browser

http://127.0.0.1:8000/
